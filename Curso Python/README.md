## 🎯 Objetivo do Módulo

Este módulo aborda a aplicação de Python em duas áreas centrais para a engenharia de dados: **automação de processos** e **manipulação de dados**. O foco foi desenvolver habilidades práticas na extração de dados de fontes web utilizando Selenium e no processamento e análise desses dados com as poderosas bibliotecas Pandas e NumPy.

O projeto final integra esses conceitos, demonstrando um fluxo de trabalho que vai desde a coleta automatizada de informações na web até a sua estruturação e análise.

---

## 📂 Estrutura e Conteúdo

Os diretórios deste módulo estão organizados por temas, cobrindo desde os fundamentos da linguagem até as bibliotecas especializadas.

### 1. `Primeiros comandos`
Esta seção cobre a base da linguagem Python e as bibliotecas fundamentais para a ciência de dados.

* **`1.Comandos Basicos`**: Introdução a variáveis, tipos de dados, operadores e estruturas de controle (`if`, `else`).
* **`2.Comandos intermediários`**: Aprofundamento em laços de repetição (`for`, `while`), listas, tuplas e dicionários.
* **`3.Outros comandos`**: Exploração de funções, manipulação de arquivos e tratamento de exceções (`try`, `except`).
* **`4.Ndarrays`**: Introdução à biblioteca **NumPy** para a criação e manipulação de arrays multidimensionais, uma base para a computação numérica em Python.
* **`5.Pandas`**: Foco na biblioteca **Pandas**, abordando a criação de DataFrames, leitura de arquivos (CSV, Excel), seleção e filtragem de dados (`loc`, `iloc`), e operações básicas de análise.

### 2. `Automação Web`
Nesta pasta está o projeto prático de automação web, que utiliza a biblioteca **Selenium** para interagir com navegadores.

* **Objetivo do Projeto**: Desenvolver um robô (bot) capaz de navegar em um site, preencher formulários, clicar em botões e extrair informações de forma automatizada.
* **Habilidades Aplicadas**:
    * Inicialização e controle de um WebDriver.
    * Localização de elementos da página (por ID, XPath, CSS Selector).
    * Envio de dados para campos de texto (`send_keys`).
    * Simulação de cliques em elementos interativos (`click`).

### 3. `SQL Server`
Esta seção contém scripts que demonstram a integração do Python com bancos de dados relacionais.

* **Objetivo**: Conectar a um banco de dados SQL Server para executar consultas e extrair dados diretamente para um ambiente Python (provavelmente para um DataFrame do Pandas).
* **Bibliotecas Comuns**: `pyodbc`, `sqlalchemy`.

## 🛠️ Principais Habilidades Desenvolvidas

* **Fundamentos de Python**: Lógica de programação, estruturas de dados e funções.
* **Análise de Dados**: Manipulação e análise de dados tabulares com **Pandas** e computação numérica com **NumPy**.
* **Web Scraping & Automação**: Extração de dados e automação de tarefas em websites com **Selenium**.
* **Conectividade com Bancos de Dados**: Habilidade de integrar Python com SQL Server para consultar e manipular dados.
