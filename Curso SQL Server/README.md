## 🎯 Objetivo do Módulo

Este módulo é um guia prático para dominar o **SQL Server**, focando nas habilidades essenciais para a **engenharia e análise de dados**. O objetivo é ir além dos comandos básicos de SQL e aprofundar em tópicos como otimização de performance, gerenciamento de dados complexos e integração com outras ferramentas, preparando você para construir e manter bancos de dados robustos.

---

## 📂 Estrutura e Conteúdo

Os diretórios deste módulo estão organizados para um aprendizado progressivo, do fundamental ao avançado.

### 1. `Fundamentos do SQL Server`
Esta seção estabelece a base teórica e prática para começar a trabalhar com bancos de dados.

* **`1.Introducao`**: Guia de instalação e configuração do SQL Server e SQL Server Management Studio (SSMS).
* **`2.Comandos Basicos`**: Introdução aos comandos DDL (`CREATE`, `ALTER`, `DROP`) e DML (`SELECT`, `INSERT`, `UPDATE`, `DELETE`).

### 2. `Consultas Avançadas`
Aprofundamento em técnicas de consulta que otimizam a extração e a análise de dados.

* **`1.Joins`**: Exploração detalhada de `INNER`, `LEFT`, `RIGHT`, e `FULL OUTER JOINs` para combinar tabelas.
* **`2.Subqueries`**: Uso de subconsultas para consultas aninhadas e complexas.
* **`3.CTE e Funcoes de Janela`**: Criação de Common Table Expressions para consultas mais legíveis e utilização de funções analíticas.

### 3. `Manipulação e Gerenciamento`
Foco em técnicas de gerenciamento e manipulação de dados para um fluxo de trabalho eficiente.

* **`1.Trabalhando com Variaveis`**: Uso de variáveis e estruturas de controle (`IF`, `WHILE`) em scripts.
* **`2.Stored Procedures`**: Criação e execução de procedimentos armazenados para automação e segurança.
* **`3.Views e Indices`**: Criação de `views` para simplificar consultas e de `indices` para otimizar a performance.

---

## 🛠️ Principais Habilidades Desenvolvidas

* **Fundamentos de T-SQL**: Domínio da linguagem SQL e suas especificidades no SQL Server.
* **Análise de Dados Relacionais**: Habilidade de extrair, filtrar e combinar dados de múltiplas tabelas de forma eficiente.
* **Otimização de Consultas**: Conhecimento de técnicas para otimizar o desempenho de queries e planos de execução.
* **Automação e Manutenção**: Capacidade de criar objetos como `Stored Procedures` e `Views` para tarefas recorrentes.
