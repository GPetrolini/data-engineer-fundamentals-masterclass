## 🎯 Objetivo do Módulo

Este módulo completo de Excel foi projetado para construir uma base sólida em análise de dados, automação de tarefas e criação de dashboards interativos. A trilha de aprendizado progride desde os conceitos fundamentais até as ferramentas mais avançadas da plataforma, incluindo a automação com **Macros e VBA**.

O objetivo final é dominar o Excel como uma poderosa ferramenta para resolver problemas de negócio, manipular dados de forma eficiente e apresentar resultados de maneira clara e profissional.

---

## 📂 Conteúdo e Habilidades Desenvolvidas

A jornada de aprendizado foi dividida em três níveis, com projetos e exercícios práticos em cada etapa.

### Nível 1: Funções Essenciais e Lógica de Dados

O foco desta etapa foi dominar as fórmulas mais importantes para a manipulação e análise de dados do dia a dia.

* **Funções de Lógica:**
    * `SE`: Criação de condicionais simples.
    * `SE` aninhado: Múltiplos critérios e resultados.
    * `E` / `OU`: Combinação de múltiplas condições lógicas.
* **Funções de Agregação Condicional:**
    * `SOMA.SE` / `SOMASES`: Somar valores com base em um ou mais critérios.
    * `CONT.SE` / `CONT.SES`: Contar células que atendem a um ou mais critérios.
* **Funções de Pesquisa e Referência:**
    * `PROCV` (VLOOKUP): Busca de dados em colunas.
    * `PROCH` (HLOOKUP): Busca de dados em linhas.
    * `PROCX` (XLOOKUP): A evolução mais flexível e poderosa das funções de busca.
* **Funções de Texto e Data:** Manipulação de datas e extração de texto (`ESQUERDA`, `DIREITA`).
* **Outras Fórmulas Importantes:** `SOMARPRODUTO`, `MÉDIA`.

### Nível 2: Análise de Dados e Visualização

Nesta fase, o foco foi transformar dados brutos em insights através de ferramentas de análise e visualização.

* **Tabelas Dinâmicas:**
    * Criação e formatação de relatórios sumarizados.
    * Agrupamento de dados (por data, categoria, etc.).
    * Uso de campos calculados para criar novas métricas.
* **Gráficos Dinâmicos:**
    * Criação de visualizações interativas conectadas a Tabelas Dinâmicas.
    * Análise visual de tendências e padrões nos dados.
* **Formatação Condicional:** Aplicação de regras visuais para destacar informações importantes e identificar anomalias.

### Nível 3: Automação e Dashboards

A etapa final concentrou-se em automatizar tarefas repetitivas e consolidar as análises em um painel de controle interativo.

* **Automação com Macros:**
    * Gravação de macros para automatizar tarefas de formatação e geração de relatórios.
    * Criação de macros para gerar gráficos automaticamente.
* **Introdução ao VBA (Visual Basic for Applications):**
    * Desenvolvimento de um formulário de cadastro (`UserForm`) para inserir dados em uma planilha de forma controlada e intuitiva.
* **Criação de Dashboards:**
    * Consolidação de múltiplas análises (Tabelas e Gráficos Dinâmicos) em uma única tela.
    * Uso de **Segmentação de Dados (Slicers)** para criar filtros interativos e dinâmicos para o dashboard.

---

Este módulo proporcionou um domínio completo sobre o ciclo de vida da análise de dados dentro do Excel, desde a importação e limpeza até a automação e apresentação em dashboards profissionais.
